概述

LLSDA（闪电定位系统数据分析器）是一个开源、跨平台的类库，用于分析闪电定位系统数据。

主要特性

  • 跨平台 (.NET Framework 4.8 / .NET Standard 2.0)
  • 多格式闪电数据文件解析 (ADTD/GLD360/WWLLN)
  • 年/月/小时时间分布分析
  • 空间分布和雷击密度计算（方格网/同心圆）
  • 基于经纬度的点查询分析
  • 雷电玫瑰图和电流强度概率图
  • GIS Shapefile 叠加与 MeteoInfo 集成

安装方法

Install-Package LightningLocationSystemDataAnalyzer-LLDSA
dotnet add package LightningLocationSystemDataAnalyzer-LLDSA

快速开始

using LLDSA;
using LLDSA.Entities.FileOperator.LLSFileProcessor.ADTD;
using System.Collections.Generic;
using System.IO;
using System.Text;

// 1. 创建文件处理器并指向数据文件 (ADTD格式)
var processor = new ADTDFileProcessor();
processor.SourceLlsFilePathName = @"data\2008_07_09.txt";
processor.Province = "";
processor.Encode = Encoding.UTF8;

// 2. 解析所有记录并返回强类型对象列表
List strikes = processor.ReturnStrikesChinaByProcess().ToList();
Console.WriteLine($"成功解析 {strikes.Count} 条雷击记录。");
