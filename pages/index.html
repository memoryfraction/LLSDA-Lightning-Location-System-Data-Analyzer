Features | 法性

Cross-Platform

.NET Framework 4.8 + .NET Standard 2.0 - Windows/Linux/macOS.

File Parsing

Multiple lightning location system data formats.

Time Distribution

Year/month/hour distribution analysis and charting.

Spatial Statistics

Area-based lightning flash density calculation.

Rose Diagram

Lightning rose diagram visualization.

GIS Support

Shapefile overlay with MeteoInfo GIS integration.
