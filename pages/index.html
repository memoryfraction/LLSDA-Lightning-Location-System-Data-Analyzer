Features

Cross-Platform

.NET Framework 4.8 + .NET Standard 2.0 — Windows/Linux/macOS.

File Parsing

Multiple lightning location system data formats (ADTD/GLD360/WWLLN).

Time Distribution

Year/month/hour distribution analysis and charting.

Spatial Statistics

Area-based lightning flash density calculation with square grid / concentric circles.

Rose Diagram

Lightning rose diagram visualization.

GIS Support

Shapefile overlay with MeteoInfo GIS integration.

Installation

NuGet Package Manager:

Install-Package LightningLocationSystemDataAnalyzer-LLDSA

.NET CLI:

dotnet add package LightningLocationSystemDataAnalyzer-LLDSA
