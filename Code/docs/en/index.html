Overview

LLSDA (Lightning Location System Data Analyzer) is an open-source, cross-platform class library for analyzing lightning location system data.

Key Features

  • Cross-platform (.NET Framework 4.8 / .NET Standard 2.0)
  • Multiple lightning data file format parsing
  • Year, month, hour distribution analysis
  • Spatial distribution and flash density calculation
  • Point-based lat/lng query analysis
  • Rose diagram and intensity probability charts
  • GIS Shapefile overlay with MeteoInfo integration

Installation

Install-Package LightningLocationSystemDataAnalyzer-LLDSA
dotnet add package LightningLocationSystemDataAnalyzer-LLDSA

Quick Start

using LLDSA;
using LLDSA.Entities.FileOperator;
using System.Collections.Generic;
using System.IO;
using System.Text;

var strikes = new List<BaseStrikeChina>();
var srcFile1 = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, @"data\2008_07_09.txt");

if (File.Exists(srcFile1))
{
    var fileProcessor = new LlsFileProcessor(srcFile1, Encoding.UTF8);
    strikes.AddRange(fileProcessor.ReturnStrikesChinaByProcess());
}
